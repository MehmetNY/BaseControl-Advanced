# Custom mode: a slider only DRAFTS a value; nothing reaches the laptop until its Confirm button is pressed. The readings are LIVE.
# Run: ControlCenterAdvanced.exe --sim --script tests/ui/custom_flow.txt --size 1360x1500   (simulator, Wine or Windows)
say == 1. in a ready-made mode the values are only shown: live, but locked ==
page custom
wait 600
expect profile.active Overboost
expect ec.pl1 120
expect perf.pl1 120
dragid sl#perf.pl1 0.3
expectdraft perf.pl1 0
clickid ok#perf.pl1
clickid sw#perf.tcc.on
wait 1500
expect ec.pl1 120
expect perf.tcc.on 0
expect perf.pl1.profile 120
external ec.pl1 110
wait 1500
expect perf.pl1 110
external ec.pl1 120
wait 1500
expect perf.pl1 120
shot /tmp/shots/c0_readymade.png
