This file says what the program contains, what it learned from, and what it deliberately does not contain.
The same list is shown in the program on Device info > About.


1. What is in the program
-------------------------

* Control Center Advanced itself: written from scratch for this project.

* MONSTER GPU POWER (source folder src/mgp): the author's own GPU power project, GPL-3.0.
  https://github.com/MehmetNY/Monster-XMG-Gpu-Power-Control
  Its engine drives the GPU power (cTGP) control and, when you switch it on, the OEM profile file
  synchronisation.

* The C and C++ runtime. The executable is linked statically against the MinGW-w64 runtime and the GNU
  C++ runtime libraries (libgcc, libstdc++), which are distributed under their own licences, including
  the GCC Runtime Library Exception.

* Parts of Windows (GDI+, Winsock for the loopback connection, Setup API, WLAN, power profiles, Service
  Control Manager, Task Scheduler, ...) are used through their documented interfaces. They are not part of
  this program and are not redistributed.


2. What it learned from (nothing below is included)
---------------------------------------------------

These projects were read to understand how the hardware behaves and how a control centre can be
organised. No source file, text or data file of any of them is included in Control Center Advanced.
Facts about the hardware (which register means what) are not copyrightable; docs/REGISTERS.md lists the
registers the program uses and what is known about each. Licences were read from the projects' own files.

  RevoHelper                           MIT
    https://github.com/AstralMemory/RevoHelper
    A light, free control app for a sibling laptop brand: a model for a smaller and faster alternative.

  HydroControl                         MIT
    https://github.com/Gumwars/HydroControl
    A Linux control centre for a sibling laptop: notes on the shared embedded controller and on
    guarding writes.

  tongfang-uniwill-dkms / tuxedo-drivers   GPL-2.0-or-later
    https://github.com/arbitrary-string/tongfang-uniwill-dkms
    Linux drivers for the Uniwill embedded controller: what its registers mean.

  clevo-control-panel                  GPL-3.0
    https://github.com/arbitrary-string/clevo-control-panel
    Keyboard light, charge limit and performance-mode ideas for Clevo and Tongfang laptops.

  TUXEDO Control Center (archive)      GPL-3.0
    https://github.com/arbitrary-string/tuxedo-control-center-archive
    Profiles, fan curves and settings of a mature control centre for the same laptop family.

  MechControl                          no licence stated - read as a reference only
    https://github.com/Liddo-kun/MechControl-RE
    A native Windows replacement for the OEM app on Uniwill-built laptops.

  tongfang-gm7mg7p-re                  no licence stated - read as a reference only
    https://github.com/ElDavoo/tongfang-gm7mg7p-re
    Reverse-engineering notes for the embedded controller of a sibling laptop.

  Unbound-Power                        no licence stated - read as a reference only
    https://github.com/Heavyfail/Unbound-Power
    A GPU power-unlock tool.

Where a project states no licence, nothing was copied from it.


3. What is deliberately not included
------------------------------------

* The OEM Control Center (version 4.9.47.11 was the reference for the feature list and for the way its
  window talks to its service): no OEM code, driver, image, string table, certificate or file is included,
  and none of the OEM's Internet server addresses, signing keys or account credentials is in the program.
  What the program does contain is what it needs to talk to the OEM service on the same computer: the
  loopback address, the topic names and message structure of that local interface (facts about an
  interface, read from the OEM's own program files on the owner's machine and written down in
  docs/PROTOCOL.md), and the client name pattern that the OEM's own window uses to introduce itself to the
  loopback-only broker (src/oem/proto.cpp). The program reaches the embedded controller through the OEM's
  own ACPIDriver device when it is installed on the laptop; it neither ships nor modifies it, and it
  neither ships, stops nor replaces the OEM's services.

* PawnIO and any other driver for reading processor registers. An earlier beta of this program could use
  PawnIO (https://github.com/namazso/PawnIO) for an advanced CPU panel; this version has no such panel and
  no driver of any kind.
